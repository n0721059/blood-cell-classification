# Blood Cell Classification

This repository contains code and notebooks for classifying normal and abnormal blood cells using deep learning.

## 📁 Structure
- `data/`: Local data directory (**not tracked by Git**)
- `notebooks/`: Exploratory Data Analysis, augmentation, and model training
- `src/`: Reusable utility functions
- `reports/`: Figures and evaluation results
